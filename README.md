# Digital Media Content Portal (MERN)

## Run (2 terminals)
Terminal 1 (backend):
    cd server
    npm install
    npm run dev
  Wait for: "API running on port 5000"
  (No MongoDB installed? It automatically starts a temporary built-in database. Needs internet on first run.)
  (Have MongoDB? Start it first and data will be saved permanently.)

Terminal 2 (frontend):
    cd client
    npm install
    npm run dev
  Open http://localhost:5173
